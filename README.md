# qoi-go

A Go implementation of the [Quite OK Image format](https://qoiformat.org),
based on the [QOI specification](qoi-specification.pdf).

It includes an encoder, a decoder, support for Go's `image` package, and a
small command-line converter. The encoder matches the reference C
implementation byte-for-byte.

## Quick start

```sh
go run . encode input.png          # writes input.qoi
go run . decode input.qoi          # writes input.png
go run . info input.qoi
```

You can also choose the output path:

```sh
go run . -e input.png output.qoi
go run . -d output.qoi restored.png
```

To build a binary instead:

```sh
go build -o qoi .
./qoi encode input.png
```

## Library

The codec is in the `qoi` package:

```go
import qoi "github.com/dshot/qoi-go/qoi"

img, err := qoi.DecodeImage(r) // raw RGB/RGBA pixels
err = qoi.EncodeImage(w, img)
```

It also works with the standard image package:

```go
m, err := qoi.Decode(r) // returns *image.NRGBA
err = qoi.Encode(w, m)
```

Importing the package registers QOI with `image.Decode` and
`image.DecodeConfig`.

## Project layout

- `qoi/` — the reusable codec
- `main.go` — the command-line tool
- `qoi-specification.pdf` — the format specification
